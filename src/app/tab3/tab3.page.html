About BookShelf

PROJECT DATA MODEL

Book collection

Each book record includes these fields:

Title

Book name

 Author

Writer’s name

 Genre

Book category

 ISBN

Unique publication identifier

 Status

To Read, Reading, or Finished

 Features Search, status filters, edit/delete confirmations, toast messages, loading indicators, pull-to-refresh, and drag-to-reorder are built into the app. Books are saved in Firebase Realtime Database and are available across devices connected to this project.
